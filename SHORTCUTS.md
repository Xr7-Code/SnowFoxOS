# ⌨️ SnowFoxOS Keyboard Shortcuts

Vollständige Referenz aller Tastenkombinationen.

**Hinweis:** `Mod` = Windows/Super-Taste

## 📱 Apps & Launcher

| Shortcut | Aktion |
|----------|--------|
| `Mod+Return` | Terminal öffnen (Kitty) |
| `Mod+B` | Firefox starten |
| `Mod+E` | Dateimanager (Thunar) |
| `Mod+R` | App-Menü (alle installierten Apps) |
| `Ctrl+Space` | Smart Launcher (Apps + Files durchsuchen) |

## ⚙️ System

| Shortcut | Aktion |
|----------|--------|
| `Mod+,` | SnowFox Settings |
| `Mod+N` | WiFi Manager |
| `Mod+X` | Bildschirm sperren |
| `Mod+H` | Shortcuts-Hilfe anzeigen |
| `Power-Button` | Power-Menü (Herunterfahren, Neu starten, etc.) |

## 🗔 Workspaces

| Shortcut | Aktion |
|----------|--------|
| `Mod+1` bis `Mod+5` | Zu Workspace 1-5 wechseln |
| `Mod+Shift+1` bis `Mod+Shift+5` | Fenster zu Workspace 1-5 verschieben |
| `Mod+Tab` | Nächster Workspace |
| `Mod+Shift+Tab` | Vorheriger Workspace |

## 💡 Tipps

### Workspace-Workflow

1. `Mod+1` - Browser (Firefox)
2. `Mod+2` - Code (VSCode, Terminal)
3. `Mod+3` - Files (Thunar)
4. `Mod+4` - Media
5. `Mod+5` - System

### Effizient arbeiten

- **Smart Launcher (`Ctrl+Space`)** - Schnellster Weg zu Apps & Files
- **Vim-Navigation (`Mod+H/J/K/L`)** - Keine Maus nötig
- **Floating Windows (`Mod+Space`)** - Für Dialoge & Tools

### Window Management

```
Mod+W = Tabs     Mod+S = Stack    Mod+D = Split
┌──────────┐    ┌──────────┐    ┌─────┬─────┐
│  ▬▬▬▬▬   │    │    1     │    │  1  │  2  │
│          │    ├──────────┤    │     │     │
│          │    │    2     │    ├─────┴─────┤
│          │    ├──────────┤    │     3     │
└──────────┘    │    3     │    └───────────┘
                └──────────┘
```
