# SnowFoxOS v4 — Package Audit

Generated by `lib/base_system.sh:audit_recommends()` during the
installer run. Raw log: `/var/log/snowfox/recommends-audit.log`.

**Policy:** `APT::Install-Recommends "false"; APT::Install-Suggests "false";`
(`installer/apt/99-snowfox`). Every package in the explicit lists
must therefore be a real dependency, not a recommend.

## How the audit works

For each package in `BASE_PACKAGES`, the installer runs:

    apt-get install -s --no-install-recommends <pkg>   # baseline
    apt-get install -s <pkg>                            # with recommends

The difference (recommends-only packages) is written to the log.
A non-empty diff means the explicit list is *probably* complete
for that package, but it is worth checking whether the recommends
are needed (e.g. firmware blobs, language packs).

## Known result categories

- **`firmware-*`**: recommends are often needed on real hardware.
  Explicitly added to `BASE_PACKAGES` where relevant
  (`firmware-linux` in `kernel_drivers.sh`, `firmware-misc-nonfree`
  unconditionally).
- **`fonts-*`**: only the explicit ones in `desktop_environment.sh`
  are needed (JetBrainsMono Nerd Font from the repo assets, plus
  DejaVu/Liberation/Noto-Emoji).
- **`*-dev`**: `libx11-dev` and `libimlib2-dev` are added
  explicitly for the foxdock build and purged in
  `cleanup_final.sh` after the build.
- **`qt5-*` / `qt6-*`**: only the style plugins, not the full
  Qt Creator stack.

## Update procedure

1. Run the installer once on a clean VM (git-clone path).
2. Inspect `/var/log/snowfox/recommends-audit.log`.
3. For each non-empty diff, decide:
   - **explicit add** → append to `BASE_PACKAGES` in `base_system.sh`
   - **safe to omit** → no action, the package stays excluded
   - **must remove the exclusion** → document why in this file
4. Re-run the installer, confirm the log is empty for handled
   packages.
